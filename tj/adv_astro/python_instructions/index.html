What is Python?

Python is a widely used programming language in science. In Advanced Astronomy, we use it as a readable calculator and as a way to repeat, check, and extend a calculation without starting over each time.

The examples on this page run directly in your browser. Change a value and select Run Code. In Jupyter, the equivalent action is Shift+Enter.

WarningCommon beginner mistakes
  • Python uses ** for exponentiation. The symbol ^ means something else.
  • A single = assigns a value. A double == compares two values.
  • Indentation is part of Python syntax.
  • Python’s trigonometric functions use radians unless you convert explicitly.
  • In a notebook, run earlier cells that define variables or imports before a later cell tries to use them.

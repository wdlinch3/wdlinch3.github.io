# Sun–Jupiter Lagrange Dynamics

Static GitHub Pages edition of the planar circular restricted three-body laboratory.

The model uses a massless probe, normalized Sun–Jupiter parameters, a co-rotating setup frame, an inertial display transform, and a Jacobi-constant diagnostic. It is a teaching model, not a full Solar-System integration.

## Source and release notes

The interactive source is maintained separately from the Jekyll book so that future laboratories can share simulation code and validation practices. This folder is the built, self-contained public edition.

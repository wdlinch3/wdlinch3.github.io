Teaching

Minicourses

Local snapshots of public guided-study packets and source materials for compact mathematical and physical minicourses.

These materials are copied from the public minicourses release repository so the student-facing artifacts can be read from this site. The collection is uneven by design: some minicourses are rendered web notes with matching PDFs, some are older PDF packets, and some also expose source notebooks or TeX files for guided work.

Groups

A mechanics-oriented introduction to rotations, vectors, covectors, index notation, and the matrix language behind rotation groups. Starts from 3D linear algebra and rotations, then moves toward SO(2), SO(3), SO(n), and standard matrix groups.

Sturm–Liouville

A Research Club packet connecting finite-dimensional linear algebra to function spaces and analysis. Covers eigenvectors, adjoints, self-adjoint operators, Gram-Schmidt, orthogonal polynomials, Fourier series, and Sturm-Liouville problems.

View HTML Read PDF

Source: Markdown, TeX

Status: polished Quarto; legacy source files preserved

Time Translations

A packet on time evolution by analogy with spatial translations. Identifies energy as the generator of time translations, derives Hamilton's equations, introduces Poisson brackets, and points toward Hamiltonian quantization.

View HTML Read PDF

Source: Notebook, TeX

Status: polished Quarto

Quantum Mechanics to Electromagnetism

A derivation of electromagnetism from local quantum phase changes. Develops gauge covariance, vector potentials, the Aharonov-Bohm effect, differential forms, current, metric structure, Hodge duals, and Maxwell's equations.

Source: Notebook

Status: polished Quarto

Electromagnetism in Differential Forms

A compact rewriting of Maxwell theory using differential forms. Moves from integral and vector-calculus formulations to the Faraday tensor, compact Maxwell equations, gauge invariance, and the Maxwell action.

Source: TeX

Status: polished Quarto

General Relativity

A PDF packet on the geometric structures behind general relativity. Moves from action-at-a-distance concerns to metrics as dynamical fields, spacetime geometry, and coordinate-independent formulation.

View HTML PDF

Source: QMD Legacy: PDF TeX

Status: Polished Quarto HTML + PDF

Renormalization

A guided problem packet on renormalization in a solvable quantum-mechanical model: a particle in two dimensions with an attractive delta-function potential. Leads through Green functions, logarithmic divergences, running coupling, beta functions, dimensional transmutation, asymptotic freedom, and the scale anomaly.

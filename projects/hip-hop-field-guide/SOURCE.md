# Publication provenance

This directory is the deployed HTML snapshot of the public working edition of *The Message and the Method*.

The canonical editable source is `/Users/wdlinch3/Documents/ChatGPT/music/hip-hop-field-guide`, including `_quarto.yml`, the `.qmd` chapters, `sources.md`, `candidate_manifest.csv`, `coverage_matrix.csv`, and the reproducible research-ledger builder. Update that source, render it with Quarto, run `python3 scripts/validate_project.py`, and then replace this deployed snapshot from `_book/`.

Do not edit the generated HTML or `site_libs/` in this directory by hand. The CSV manifests and downloadable workbook are copied alongside the rendered site for transparent research status. This snapshot is a research edition: the 220 workbook positions are provisional, only three source-level metadata checks are complete, and no selection has been accepted into the final curriculum or resolved into the SoundCloud playlist.
